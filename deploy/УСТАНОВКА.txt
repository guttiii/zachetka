# УСТАНОВКА — Зачётная книжка (мини-приложение Telegram)

В этой папке 4 файла, все нужны:
- index.html — само приложение (дизайн Apple)
- bot.py — бот-сервер (шлёт уроки/ДЗ в чат, хранит курс, ИИ)
- requirements.txt — список библиотек (для хостинга)
- Procfile — команда запуска (для хостинга)

Установка занимает ~30 минут. Ничего программировать не нужно.

────────────────────────────────────────────
ШАГ 1. Создай бота (5 минут)
────────────────────────────────────────────
1. В Telegram открой @BotFather → отправь /newbot
2. Придумай имя и юзернейм бота
3. BotFather пришлёт ТОКЕН вида 1234567:AAE-xxxx — сохрани его
4. Открой @userinfobot → он покажет твой Id (число) — сохрани, это OWNER_ID
   (по нему сервер понимает, что владелец — именно ты)

────────────────────────────────────────────
ШАГ 2. Загрузи файлы на GitHub (10 минут)
────────────────────────────────────────────
GitHub — это просто место, откуда хостинг возьмёт файлы.
1. Зарегистрируйся на github.com
2. Нажми «+» вверху справа → New repository → имя например zachetka → Create
3. На странице репозитория: «uploading an existing file»
4. Перетащи туда все 4 файла из этой папки → Commit changes

────────────────────────────────────────────
ШАГ 3. Запусти сервер на Railway (10 минут)
────────────────────────────────────────────
1. Зайди на railway.com → Login → войди через GitHub
2. New Project → Deploy from GitHub repo → выбери свой zachetka
3. Railway сам всё соберёт и запустит (1–2 минуты)
4. Открой сервис → вкладка Variables → добавь переменные:
      BOT_TOKEN = токен из шага 1
      OWNER_ID  = твой Id из шага 1
      ANTHROPIC_API_KEY = ключ с console.anthropic.com (нужно только для вкладки ИИ,
                          можно пропустить и добавить потом)
5. Вкладка Settings → Networking → Generate Domain
   Появится адрес вида https://zachetka-production.up.railway.app — скопируй его
6. Вернись в Variables → добавь ещё одну:
      WEBAPP_URL = этот адрес (с https://, без слэша в конце)
   Railway сам перезапустит сервер.

Важно про деньги: Railway даёт пробные $5. Дальше — план Hobby ~5$/мес.
Такой сервер должен работать постоянно, «бесплатно навсегда» тут не бывает.

────────────────────────────────────────────
ШАГ 4. Подключи вебхук (1 минута)
────────────────────────────────────────────
Открой в браузере одну ссылку, подставив СВОЙ токен и СВОЙ адрес:

https://api.telegram.org/botТОКЕН/setWebhook?url=АДРЕС/webhook

Пример:
https://api.telegram.org/bot1234567:AAE-xxxx/setWebhook?url=https://zachetka-production.up.railway.app/webhook

Должно ответить: {"ok":true,...}

────────────────────────────────────────────
ШАГ 5. Проверь (2 минуты)
────────────────────────────────────────────
1. Открой своего бота в Telegram → /start → появится кнопка «📓 Открыть дневник»
2. Внутри приложения ты увидишь тумблер «Режим владельца» (ученики его не видят)
3. Отредактируй что-нибудь → нажми «🚀 Опубликовать изменения ученикам»
4. Нажми урок или ДЗ — сообщение придёт тебе в чат с ботом
5. Дай ссылку на бота ученику с другого телефона — у него будет готовый
   вариант без режима владельца

────────────────────────────────────────────
Если что-то не работает
────────────────────────────────────────────
- Кнопка не появляется по /start → проверь шаг 4 (вебхук) и WEBAPP_URL
- «Режим владельца» не появляется у тебя → проверь OWNER_ID (это число, без кавычек)
- Вкладка ИИ пишет «не подключён» → добавь ANTHROPIC_API_KEY в Variables
- Приложение открывается, но уроки не приходят в чат → смотри логи в Railway
  (вкладка Deployments → View Logs), там будет причина
